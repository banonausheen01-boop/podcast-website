📌 About the Project

The Podcast Website is a frontend web development project designed to create a modern interface for a podcast platform.

The project focuses on:

- Clean and simple UI
- Responsive webpage design
- Attractive podcast presentation
- Easy navigation
- Structured HTML and CSS

✨ Features

- 🎧 Podcast-themed user interface
- 📱 Responsive design
- 🎨 Custom styling using CSS
- 🖥️ Simple and user-friendly layout
- 🌐 Browser-based website
- 📂 Organized project structure

🛠️ Technologies Used

- HTML5 – Structure of the website
- CSS3 – Styling and layout
- VS Code – Development environment

🚀 How to Run the Project

1. Clone the repository

git clone https://github.com/banonausheen01-boop/podcast-website.git

2. Open the project

cd podcast-website

3. Run the website

Open "index.html" in any modern web browser.

You can also use the Live Server extension in Visual Studio Code for easier development.

💻 How to Use

1. Open the website.
2. Browse the podcast interface.
3. Explore the available sections and content.
4. Use the website from desktop or mobile browsers.
